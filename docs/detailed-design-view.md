## 2. モノの描画（`src/core/ops/itemDrawings.ts`）

収納の描画も、収納であるモノの描画として同じ操作で扱う。どの操作も `OpResult` を返し、所属の層は変えない（`updatedAt` も変えない。詳細設計 4.x：描画だけの変更では変えない）。

```ts
setItemDrawing(doc, item: Id, input: { shape: Shape; rotation?: Rotation }, ctx): OpResult
moveItemDrawing(doc, item: Id, dx: number, dy: number): OpResult
rotateItemDrawing(doc, item: Id, step: 1 | -1): OpResult      // 45度単位。0〜7 を回る
reshapeItemDrawing(doc, item: Id, shape: Shape): OpResult      // 形だけ替える（回転は保つ）
removeItemDrawing(doc, item: Id): OpResult
```

| 規則 | エラー |
|---|---|
| モノが存在する | `OpError('notFound')` |
| モノの置き場が属するクウカンに描画がある（未設定は描画を持たないので、未設定のモノには付けられない） | `OpError('noDrawing')` |
| 形が `isValidShape` を通る。座標は整数 | `OpError('invalidInput')` |
| 中心が「置き場にしない」マーカーの上にない（`setItemDrawing`・`moveItemDrawing`・`reshapeItemDrawing`）。マーカーの上の判定は 4.3 の `onNotAPlace` | `OpError('onNotAPlace', 'マーカー「柱」の上には置けません')` |
| `setItemDrawing` は、すでに描画があれば置き換える。回転の既定は 0 | |
| `move`・`rotate`・`reshape`・`remove` は描画があること | `OpError('notFound')` |

- 中心が置き場の外に出るのは断らない（ずれとして印を出す。設計 7.7）。はみ出しも断らない。
- `moveItemDrawing` は形ごと平行移動する（点・長方形・多角形のすべての座標に足す）。`dx`・`dy` は整数。
- 返り値の `moved`・`created` は空。

## 3. 回転の描き方

回転は表示の座標（x に縦横比を掛けた座標。`toDisplay`）で、図形の中心のまわりに `rotation × 45` 度回す（設計 7.7：実際の縦横比に直してから掛ける）。SVG では `transform="rotate(deg, cxDisp, cy)"` を付ければよい。中心は回転で変わらないので、ずれの判定（V6）は回転を見ない。

## 4. 見せ方の計算（`src/view/model.ts`）

```ts
/** クウカンの中の置き場（クウカンそのもの＋全エリア）に直接あるモノ。中の収納の中身は入れない。 */
itemsInKuukan(doc, kuukan: Id): Item[]
/** エリア（またはクウカン）とその子孫のエリアに直接あるモノ。 */
itemsInScope(doc, kuukan: Id, area: Id | null): Item[]

/** 描画していないモノの件数。キーは置き場のID（クウカンそのもの、またはエリア）。数えるのは直接置かれたものだけ。 */
undrawnCounts(doc, kuukan: Id): Map<Id, number>

/** ずれ。モノに描画がないか、置き場のクウカンに描画がなければ null。 */
drawingOffset(doc, item: Id): Offset | null
type Offset =
  | { kind: 'ok' }
  | { kind: 'off'; drawnIn: Id | null }   // drawnIn：中心がある葉のエリア（クウカンに仕切りがなければクウカン）。外形の外なら null
/** ずれの説明。「所属：段1（描画は段2の上にあります）」「所属：段1（描画はクウカンの外にあります）」 */
offsetText(doc, item: Id, off: Offset): string

/** 置き場にしないマーカーの上か。中心が図形の内側か辺の上なら上とみなす（点のマーカーは対象外）。 */
onNotAPlace(doc, kuukan: Id, p: Point): Marker | null

/** 簡易検索の集計（9章の検索を「文字＋置き場は今のクウカン」で呼ぶ）。 */
quickSearch(doc, kuukan: Id, text: string): QuickResult
interface QuickResult {
  /** 当てはまるモノのうち、このクウカンに直接あるもの。 */
  direct: Set<Id>;
  /** このクウカンに直接ある収納ごとの、中（入れ子を含む）で当てはまる件数。0 のものは入れない。 */
  insideStorage: Map<Id, number>;
  /** 置き場ごとの当てはまる件数（直接＋そこにある収納の中）。図のハイライトと件数に使う。キーはクウカンそのもの、またはエリア。 */
  perPlace: Map<Id, number>;
}

/** 経路：外側のクウカンから順に。収納のクウカンなら、持ち主のモノの置き場をたどる。 */
kuukanTrail(doc, kuukan: Id): { kuukan: Id; name: string; via: Id | null }[]   // via：その中で次の収納が置かれている置き場
```

- ずれの判定：中心が置き場の領域（エリアなら `computeRegions` の領域。途中のエリアは子孫の和。クウカンそのものなら外形）の内側か辺の上なら `ok`。
- `drawnIn` は `leafAt(regions, tree, center)`。外形の外なら null。
- 件数の数え方は「描画していないモノ」。描画したモノは図に描くので数えない（設計 8.3）。簡易検索の `perPlace` は描画のありなしを問わない。

## 5. 画面の状態（`src/app/store.ts` に足す）

```ts
export type Screen = 'start' | 'kuukans' | 'view' | 'search' | 'editor' | 'manage' | 'settings';

export interface ViewTarget {
  kuukan: Id;
  area: Id | null;        // 選んでいるエリア
  quick: string;          // 簡易検索の文字
  focus: Id | null;       // サガシモノから来たときに強めにハイライトするモノ
  placing: boolean;       // 配置モード
}
// AppState に view: ViewTarget | null を足す。screen が 'view' のときだけ値を持つ。
```

| 操作 | 内容 |
|---|---|
| `openView(kuukan, opts?: { area?, quick?, focus? })` | `screen: 'view'`。選択・詳細は閉じる。`placing: false` |
| `selectViewArea(area: Id \| null)` | |
| `setQuick(text)` | 文字を変えたら `focus` は外す |
| `setPlacing(on)` | |
| `searchFromView()` | `setQuery({ text: quick, place: kuukan })`、`screen: 'search'`（設計 8.8） |
| `showInView(item)` | モノの置き場のクウカンを開き、`quick` にそのモノの名前、`focus` にそのモノ、`area` に置き場（エリアのとき）を入れる。未設定のモノなら未設定のクウカン |
| `setScreen('kuukans')` など | 今までどおり。`view` は null に戻す |

- 文書を開いた・新しく作った・修復を受け入れた後は `screen: 'kuukans'`（V1）。
- 文書が変わって、開いているクウカンが消えたら `kuukans` に戻す。選んでいるエリアが消えたら `area: null`、`focus` のモノが消えたら `focus: null`。
- クウカン編集を出たら、開く前の画面に戻る（`view` も戻す）。

## 6. 画面

### 6.1 上のタブ（`Header.svelte`）

「クウカン」「サガシモノ」「管理」「設定」の順。「クウカン」は `kuukans`・`view`・`editor` のときに選ばれた見た目にする。

### 6.2 クウカンの一覧（`KuukanScreen.svelte`）

- 今の一覧のまま、各行の名前（と「開く」ボタン）で `openView`。「モノを見る」は外す（クウカンビューで見る）。
- いちばん上に「未設定」を出す（件数つき。押すと未設定のクウカンビュー）。
- 収納の一覧の行も「開く」でその収納のクウカンビュー。

### 6.3 クウカンビュー（`ViewScreen.svelte`）

```
┌ 経路：クウカン › Room A › 棚A1 ──────── [編集] [配置モード] ┐
│ 簡易検索 [______] [解除] [サガシモノで続きを探す]               │
├──────────────── 図 ────────────────┬──── モノリスト ────┤
│                                      │ [＋モノを追加]      │
│                                      │ 段1 のモノ 3件      │
│                                      │ ・ドライバー  ⚠ずれ │
│                                      │ ・BOX1 [開く] 中に2件│
└──────────────────────────────────────┴──────────────────┘
（モノを選ぶと、今までのモノの詳細を右に重ねて出す。幅の狭い画面では図の下にリスト）
```

- 経路（`Breadcrumb.svelte`）：「クウカン」（一覧へ）› 外側から順にクウカンの名前。押すとそのクウカンビューを開き、`via` のエリアを選ぶ。
- 「編集」：`openKuukanEditor`（未設定には出さない）。
- 描画のないクウカン（未設定を含む）：図の代わりに「このクウカンには描画情報が設定されていません」と出し、リストだけにする。未設定以外では「クウカン編集で描く」ボタンも出す。

### 6.4 図（`view/ViewCanvas.svelte`）

- 出すもの：外形、エリア（名前）、マーカー（置き場にしないものは斜線）、モノと収納の描画（名前を添える。収納は二重線など見分けのつく描き方）、描画していないモノの件数（V4）、ずれの印（描画の角に「!」の小さな印。色だけに頼らない）。
- 拡大・縮小・移動は編集と同じ（`src/editor/view.ts` の関数を使う。ホイール・ピンチ・ドラッグ・「全体を表示」）。押した位置は `getScreenCTM()` から求める（段階5の直し）。
- 押したとき（配置モードでない）：
  - 収納の描画 → それを選び、そばに「開く」ボタンを出す（ダブルクリックは使わない）。
  - モノの描画 → そのモノの詳細を出す（`app.showDetail`）。
  - エリア → `selectViewArea`（同じエリアをもう一度押すと解除）。外形の外 → 解除。
- 簡易検索の文字があるとき：当てはまる置き場（`perPlace` が1以上）をハイライトし、件数を当てはまる件数に変える。当てはまる収納の描画もハイライトし「中に2件」を添える。`focus` のモノは、ほかより強くハイライトする。
- ハイライト（`$app.highlights`）に入ったモノの描画も目立たせる。

### 6.5 モノリスト（`view/ItemList.svelte`）

- 範囲：`itemsInScope(doc, kuukan, area)`（V3）。簡易検索の文字があれば、さらに `direct` に入るものと、`insideStorage` に入る収納だけ。
- 見出し：「Room A のモノ 6件」「段1 のモノ 3件」。エリアを選んでいるときは「選択を解除」。
- 行：名前（数量があれば横に）、置き場（エリアを選んでいないときだけ。エリア名）、カテゴリ、ずれの印（⚠ と「ずれ」の文字。押すと `offsetText` を出す）、収納なら「開く」と、簡易検索中は「中に2件」。押すとモノの詳細。`focus` と `$app.highlights` の行は目立たせる。
- 並び：置き場の順（エリアの木の順）、同じ置き場の中は名前順。
- 「＋モノを追加」：名前を入れて追加（Enter で追加、Esc で取り消し）。置き場は選んでいるエリア、なければクウカンそのもの（V2）。追加したモノの詳細を開く。

### 6.6 配置モード

- 上の「配置モード」で入る（描画のあるクウカンだけ）。入っている間はボタンが「配置を終える」になり、図の上に道具の列を出す。リストの操作はいつもどおりできる（設計 8.0）。
- リストの各行に「描画を付ける」（描画があれば「描画を選ぶ」）。押すと、そのモノを付ける相手にして、道具（点・長方形）を選ぶ。点は図を押した位置、長方形はドラッグした範囲（目盛りに吸着。`snap.ts`）。
- 図の上の描画を押すと選ばれ、ドラッグで動かせる（目盛りに吸着）。選んだ描画には「左に回す」「右に回す」（45度）、「描画を外す」、長方形と多角形なら「辺を動かす」「段差を足す」（V5。`moveEdge`・`addStep` を形の座標にそのまま使う。結果は `poly`）。
- 断られたとき（V7 など）は、理由を図の上の案内に出し、描画は動かない。
- 中心が置き場の外に出たら、離した後にずれの印が付く（断らない）。
- 「元に戻す」は文書の履歴（描画の変更も1操作ずつ戻る）。

### 6.7 編集のマーカー（段階5の残り。`editor/SidePanel.svelte`）

- 選んだ長方形・多角形のマーカーにも「辺を動かす」「段差を足す」を出す（V5。結果は `poly`）。マーカーの形の変更は `updateMarker(doc, id, { shape })`。

### 6.8 サガシモノ（`SearchScreen.svelte`、`ItemTable.svelte`）

- 「＋モノを追加」を外す（V2）。モノが1件もないときの案内は「モノはクウカンの画面から追加します」。
- 行にずれの印（6.5 と同じ）。
- 行に「クウカンで見る」（`showInView`。設計 8.8）。

## 7. 結合試験の観点（`tests/integration/view.test.ts`）

|---|---|
| V-S | 見本の文書で、一覧 → Room A → 棚A1 → BOX1 と開き、経路で戻れる。各画面の範囲のモノが置き場どおり |

| V-1 | 文書を開いた・新しく作った直後はクウカンの一覧 |
